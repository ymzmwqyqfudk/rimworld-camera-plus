## Overview

Camera+ replaces RimWorld's default camera controller with a smooth, configurable alternative that supports high-speed pan, custom zoom curves, edge-scroll tuning, and always-on minimap.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **RimWorld Camera+** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Smooth Zoom** | Exponential zoom curve with configurable speed and max distance |
| **Edge Scroll** | Adjustable edge-scroll sensitivity and dead-zone configuration |
| **Minimap Always On** | Persistent minimap overlay with zoom-to-click navigation |
| **Camera Bookmarks** | Save and recall up to 10 named camera positions |
